# AGENTS.md

The rules for every agent working in this repository are in two files. Read them before changing anything:

- [`CLAUDE.md`](CLAUDE.md) — what the repository holds, how to run and check the game, working on issues,
  the git workflow and the pipelines.
- [`gamev2/CLAUDE.md`](gamev2/CLAUDE.md) — the guide to the game itself: the checks to run, the rules for
  every change, and the index of the topic files in `gamev2/docs/`.

They apply whatever agent you are. This file only points at them, so there is one copy of the rules.
